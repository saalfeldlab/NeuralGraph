# Updating the NeuralGraph Documentation Site

## Prerequisites

- Quarto installed (`quarto --version`)
- Python with matplotlib, numpy, scipy, networkx

## Steps

### 1. Exploration Artifacts

Exploration artifacts are referenced **directly** from the log directory --- no copy step needed:

```
log/Claude_exploration/instruction_signal_landscape_parallel/
  exploration_tree/      ucb_tree_iter_NNN.png
  connectivity_matrix/   block_NNN.png
  connectivity_scatter/  iter_NNN.png
  kinograph/             iter_NNN.png
  mlp/                   iter_NNN_MLP.png
  activity/              block_NNN.png
```

All `.qmd` files reference `log/Claude_exploration/instruction_signal_landscape_parallel/` directly.
Epistemic images (`epistemic_*.png`, `Sankey.png`) are generated separately and stored in `assets/`.

### 2. Run Epistemic Analysis

**IMPORTANT**: This must be done BEFORE updating the quarto site content.

Follow the procedure in `instructions_epistemic_analysis.md` to generate three epistemic analysis files from the raw `signal_landscape_Claude_analysis.md` log:

```bash
# Output files (generated by LLM following instructions_epistemic_analysis.md):
# - signal_landscape_Claude_epistemic_analysis.md    (main summary)
# - signal_landscape_Claude_epistemic_detailed.md    (exhaustive event log)
# - signal_landscape_Claude_epistemic_edges.md       (causal relationships)
```

### 3. Regenerate Figures

```bash
# Generate quadrant chart
python plot_landscape_quadrant.py
cp landscape_quadrant.png assets/

# Generate epistemic visualizations (reads events/edges from the script)
python plot_landscape_epistemic.py
cp signal_landscape_Claude_epistemic_timeline.png assets/epistemic_timeline.png
cp signal_landscape_Claude_epistemic_streamgraph.png assets/epistemic_streamgraph.png
cp signal_landscape_Claude_epistemic.png assets/epistemic_panels.png
cp Sankey.png assets/epistemic_sankey.png
```

### 4. Update Quarto Content

Update the `.qmd` pages to reflect fresh data:

```bash
# Pages to update:
index.qmd                  # Date, iteration count, regime count, preview images
results.qmd                # Performance tables, key findings, principles
epistemic-analysis.qmd     # Driven by epistemic pipeline output (step 2)
exploration-gallery.qmd    # Tab panels for new iterations/blocks
```

### 5. Render the Site

**Manual step** — the user renders the site, do NOT run `quarto render` from Claude/LLM.

```bash
quarto render
```

### 6. Push to GitHub

```bash
git add -f docs/*.html docs/assets/ *.qmd
git commit --no-verify -m "Update documentation site"
git push
```

The site will be live at: https://saalfeldlab.github.io/NeuralGraph/
